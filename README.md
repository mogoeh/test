# Produktivitätsplan

Digitaler Wochenplan mit To-do-Liste – eine einzelne HTML-Datei (`produktivitaetsplan.html`), ohne Installation. Bedienung angelehnt an Outlook.

## Kalender
- Wochenraster Mo–Fr, 05:00–20:00 Uhr im 30-Minuten-Takt, KW-Anzeige, Sprung zu Datum, Tastatur: ← / → / T
- **Zeitraum markieren** (Maus ziehen), Titel tippen, Enter. Doppelklick oder „Details“ öffnet den vollen Dialog
- **Ganztags-Zeile** über dem Raster (z.B. „Büro München“), auch über mehrere Tage per Ziehen
- **Anzeigen als** wie in Outlook: Gebucht, Mit Vorbehalt, Außer Haus, An anderem Ort tätig, Frei
- **Eigene Kategorien** mit Farbe (Einstellungen), Standard: Beruflich, Privat
- **Ort**, Notiz, **Serien** (täglich Mo–Fr, wöchentlich, 14-tägig, monatlich, mit Enddatum); Änderung „nur dieser Termin“ oder „ganze Serie“
- Termine verschieben per Drag & Drop (auch zwischen Ganztags-Zeile und Raster), **Dauer ändern** über die Unterkante
- Wochenbilanz: verplante Stunden je Kategorie
- Löschen mit **Rückgängig**, Duplizieren

## To-dos & Ziele
- **Wochenziele** je KW (speichert automatisch)
- To-dos mit Priorität, Fälligkeit, Kategorie, Notiz; Filter nach Kategorie; fällige To-dos werden im Tageskopf angezeigt
- Einplanen: To-do ins Raster/die Ganztags-Zeile ziehen (PC) oder Kalender-Symbol (Handy)

## Speicherung
- Als claude.ai-Artifact: privater Bereich des eigenen claude.ai-Kontos, synchron zwischen Geräten. Backup als JSON über die Einstellungen.
- Lokal im Browser geöffnet: nur `localStorage` dieses Browsers.
